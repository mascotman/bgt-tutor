# BGT Tutor — ต้นแบบเว็บหาครูสอนพิเศษ

เว็บคนกลางระหว่าง **ครูสอนพิเศษ** กับ **ผู้ปกครอง/นักเรียน**
จุดขาย: คุยกันให้จบก่อน ตกลงวัน-เวลา-ราคาเรียบร้อย **แล้วค่อยจ่าย** — เงินพักไว้กับคนกลางจนคาบสอนจบและมีการยืนยัน

> ⚠️ **นี่คือต้นแบบ (prototype)** ยังไม่มีฐานข้อมูลจริงและยังจ่ายเงินจริงไม่ได้
> ข้อมูลครู/นักเรียน/งาน ทั้งหมดเป็นข้อมูลสมมติ · ค่าที่แก้จะเก็บไว้ในเบราว์เซอร์ของคุณเองเท่านั้น

## เข้าดูตรงไหน

| ฝั่ง | หน้า |
|---|---|
| **หน้าแรก** | `index.html` |
| **ครู** | สมัคร · กระดานงาน · ตารางสอน · ผลงาน · โปรไฟล์ |
| **ผู้เรียน** | สมัคร (ผู้ปกครอง / นักเรียน 16+) · โพสต์หาครู · ค้นหาครู · โปรไฟล์ครู · จองคาบ · การจองของฉัน |

## โครงไฟล์

```
index.html      หน้าแรก
teacher/        5 หน้าฝั่งครู
student/        7 หน้าฝั่งผู้เรียน
shared/         ธีม · ชิ้นส่วนที่ใช้ร่วมกัน · ข้อมูลตัวอย่าง
```

เขียนด้วย HTML/CSS/JS ล้วน ไม่มี build step — เปิดไฟล์ก็ใช้ได้เลย
